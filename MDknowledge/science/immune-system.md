# Immune system (example)

- Innate immunity (skin, inflammation, phagocytes) responds immediately and generically.
- Adaptive immunity (B/T cells) learns specific threats with memory afterward.
- Antibodies tag pathogens; killer T cells destroy infected host cells.
- Vaccines train adaptive memory without causing the disease.
- Lymph nodes filter pathogens where immune cells coordinate responses.
- Autoimmune diseases attack self tissues mistaken for invaders.
- Allergies overreact to harmless antigens like pollen or peanuts.
- Immunological memory makes second exposures faster and stronger.
- Passive immunity (maternal antibodies) protects newborns temporarily.
- Herd immunity shields the vulnerable when enough are immune.
