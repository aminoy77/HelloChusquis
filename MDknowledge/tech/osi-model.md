# OSI model

- The OSI model layers Physical, Data Link, Network, Transport, Session, Presentation, Application.
- Layer 1 Physical moves bits over cables, radio, and connectors.
- Layer 2 Data Link frames local delivery via MAC addresses and switches.
- Layer 3 Network routes packets across networks with IP addresses.
- Layer 4 Transport segments flows; TCP is reliable, UDP is fast.
- Layer 5 Session manages connections and dialogues between endpoints.
- Layer 6 Presentation translates formats, encryption, and compression.
- Layer 7 Application serves user protocols like HTTP, DNS, and SMTP.
- TCP/IP collapses OSI into Link, Internet, Transport, Application in practice.
- Troubleshoot bottom-up: cables before configs, packets before applications.
