# Common TCP ports

- Port 80 carries plain HTTP and port 443 carries HTTPS traffic.
- Port 22 serves SSH for secure shell and file transfer.
- Port 25 sends SMTP mail; 587 submits it and 993 reads IMAP securely.
- Port 53 resolves DNS names to IP addresses over UDP and TCP.
- Port 3306 serves MySQL/MariaDB and 5432 serves PostgreSQL.
- Port 6379 serves Redis and 27017 serves MongoDB by default.
- Port 8080 and 3000 are conventional local development alternates.
- Port 21 controls FTP while port 20 historically carried its data.
- Port 3389 serves Windows Remote Desktop sessions.
- Port 5900 serves VNC screen-sharing sessions.
- Port 6379 open to the internet invites cryptomining hijacks; bind locally.
- Well-known ports span 0-1023 and need privileges to bind on Unix.
