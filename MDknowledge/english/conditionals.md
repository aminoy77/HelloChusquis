# English conditionals (example)

- Zero conditional states general truths: if you heat ice, it melts.
- First conditional predicts real futures: if it rains, we will cancel.
- Second conditional imagines present alternatives: if I were rich, I would travel.
- Were (not was) marks formal second-conditional be: if I were you.
- Third conditional regrets pasts: if we had left, we would have caught it.
- Mixed conditionals cross times: if you had studied, you would know now.
- Unless equals if...not and tightens warnings: unless hurried, we miss it.
- Provided/provided that set formal conditions in contracts and rules.
- Imperatives pair with if for instructions: if lost, retrace your steps.
- Modal choice (will/would/might) calibrates conditional certainty precisely.
