# E2E testing (example)

- Playwright/Cypress drive real browsers through critical user journeys.
- Test user-visible behavior (roles, text), not CSS selectors internals.
- Page-object models centralize locators surviving redesigns.
- Network interception stubs flaky backends deterministically.
- Trace viewers replay failures step-by-step with DOM snapshots.
- Parallel sharding across CI machines compresses suite runtimes.
- Visual regression (screenshots) catches styling drift humans miss.
- Seeded test data plus isolated tenants prevent cross-test pollution.
- Flaky quarantines plus retries distinguish flakes from regressions.
- Accessibility audits (axe) ride along E2E runs nearly free.
