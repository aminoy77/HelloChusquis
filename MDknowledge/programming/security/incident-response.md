# Incident response

- Preparation (roles, runbooks, contacts) decides incidents before they start.
- Detect via alerts on symptoms plus threat intel, not user complaints alone.
- Contain first (isolate hosts, revoke keys), then eradicate root causes.
- Eradicate persistence (backdoors, scheduled tasks) before restoring services.
- Recover in stages with enhanced monitoring watching for resurgence.
- Blameless postmortems extract systemic fixes, not scapegoats.
- Preserve evidence (disk images, logs) before remediation destroys it.
- Communicate status on cadences (every 30 min) even with 'still investigating'.
- Tabletop exercises rehearse plans against realistic scenarios quarterly.
- Retainers and pre-authorized counsel accelerate legal/technical response.
