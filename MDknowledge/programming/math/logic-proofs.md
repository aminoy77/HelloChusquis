# Logic and proofs (example)

- Propositions bear truth values; connectives (∧∨¬→↔) combine them truth-functionally.
- Implication (P→Q) is false only when P holds and Q fails.
- Contrapositive (¬Q→¬P) proves equivalently and often more easily.
- Contradiction assumes negation and derives absurdity to conclude truth.
- Induction proves base plus step to cover all naturals infinitely.
- Counterexamples disprove universals with single instances decisively.
- Necessary conditions must hold; sufficient conditions guarantee conclusions.
- Quantifier order matters: ∀x∃y differs profoundly from ∃y∀x.
- Truth tables exhaust small cases mechanically but explode exponentially.
- Vacuous truths (false antecedents) make implications true by convention.
