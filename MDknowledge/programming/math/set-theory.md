# Set theory (example)

- Sets collect distinct elements; order and repetition are meaningless in them.
- Union (∪), intersection (∩), and difference (−) combine sets elementwise.
- Venn diagrams visualize two- and three-set overlaps intuitively.
- Subsets (⊆) include equality; proper subsets (⊂) exclude it.
- Empty set (∅) subsets everything; power sets hold all 2ⁿ subsets.
- De Morgan's laws negate unions into intersections and vice versa.
- Cartesian products pair every element across sets for grid reasoning.
- Cardinality counts elements; infinite sets compare via bijections.
- Russell's paradox (set of all non-self-containing sets) broke naive theory.
- ZFC axioms rebuilt foundations avoiding self-reference traps.
