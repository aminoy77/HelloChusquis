# Counting combinatorics (example)

- Multiplication principle multiplies independent choice counts stage by stage.
- Permutations P(n,k) = n!/(n−k)! order k picks from n distinctly.
- Combinations C(n,k) = n!/(k!(n−k)!) ignore order within picks.
- Stars-and-bars counts distributions of identical items into bins.
- Inclusion-exclusion alternately adds/subtracts overlaps for unions.
- Pigeonhole principle forces shared boxes past capacity counts.
- Binomial theorem expands (x+y)ⁿ with C(n,k) coefficients exactly.
- Pascal's triangle visualizes recurrence C(n,k) = C(n−1,k−1) + C(n−1,k).
- Derangements count fixed-point-free permutations (~n!/e).
- Complementary counting solves hard 'at least' via easier 'none' cases.
