# Rust Cargo

- In Rust, `cargo new --bin app` scaffolds binaries and `--lib` scaffolds libraries.
- In Rust, `Cargo.toml` declares package metadata plus `[dependencies]` versions.
- In Rust, `cargo build` compiles debug fast and `--release` optimizes for shipping.
- In Rust, `cargo test` runs unit, integration (`tests/`), and doc tests together.
- In Rust, `cargo fmt` formats and `cargo clippy` lints with pedantic suggestions.
- In Rust, `cargo doc --open` renders crate documentation including examples.
- In Rust, `cargo update` refreshes `Cargo.lock` within declared version constraints.
- In Rust, features (`[features]`) compile optional functionality behind flags.
- In Rust, workspaces (`[workspace] members`) coordinate multi-crate repositories.
- In Rust, `cargo audit` flags dependencies with known vulnerabilities.
