# VPN essentials

- VPNs tunnel private traffic across public networks with encryption.
- WireGuard's tiny codebase audits easier than legacy IPsec suites.
- OpenVPN's maturity suits restrictive networks via TCP/443 camouflage.
- Split tunneling routes only corporate traffic VPN, saving bandwidth.
- Kill switches block leaks when tunnels drop unexpectedly.
- Site-to-site VPNs bridge whole networks; remote-access serves roaming users.
- Zero-trust (BeyondCorp-style) identity checks per request can replace VPNs.
- DNS leaks expose browsing despite tunnels; test with leak-check tools.
- Commercial VPNs shift trust to the provider; self-host for control.
- Latency grows with distance to exit nodes; pick nearby endpoints.
