# JavaScript URL API

- In JavaScript, `new URL(str)` parses; invalid input throws TypeError.
- In JavaScript, `url.searchParams` gets/sets query entries with encoding handled.
- In JavaScript, `URL.createObjectURL(blob)` makes temporary download links (revoke after).
- In JavaScript, `new URL(path, base)` resolves relatives against bases safely.
- In JavaScript, `url.origin` exposes scheme+host+port for allow-list checks.
- In JavaScript, `URL.canParse` (modern) validates without try/catch.
- In JavaScript, `location` mirrors the document URL with assign/reload navigation.
- In JavaScript, never trust client-parsed URLs for auth decisions server-side.
