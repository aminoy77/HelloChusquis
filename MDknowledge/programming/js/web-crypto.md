# Web Crypto API

- In JavaScript, `crypto.getRandomValues` fills secure random bytes client-side.
- In JavaScript, `crypto.subtle.digest('SHA-256', data)` hashes asynchronously.
- In JavaScript, `SubtleCrypto` AES-GCM encrypts with nonces never reused.
- In JavaScript, crypto requires secure contexts (HTTPS or localhost).
- In JavaScript, key objects (`CryptoKey`) stay non-extractable by default.
- In JavaScript, PBKDF2/Argon2-wasm stretch passwords before transmission.
- In JavaScript, `crypto.randomUUID()` generates v4 UUIDs natively.
- In JavaScript, verify signatures client-side only for UX; enforce server-side.
