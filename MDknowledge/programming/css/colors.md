# CSS colors

- In CSS, hex `#f5a623`, `rgb()`, and `hsl()` all express colors; HSL reads hue-first for theming.
- In CSS, alpha channels (`#rrggbbaa`, `rgba`, `hsla`) layer translucency over backgrounds.
- In CSS, `currentColor` inherits the text color into borders, shadows, and SVG fills.
- In CSS, CSS variables (`--brand`) centralize palettes to single change points.
- In CSS, `color-scheme: light dark` opts form controls into native dark rendering.
- In CSS, `prefers-color-scheme` media queries switch themes with the OS setting.
- In CSS, `color-mix(in srgb, red 50%, white)` blends palette steps without preprocessors.
- In CSS, contrast ratios of 4.5:1 (text) keep body copy WCAG AA compliant.
- In CSS, `opacity` fades whole subtrees including children, unlike translucent backgrounds.
- In CSS, gradients (`linear-gradient`) paint multi-stop backgrounds without images.
