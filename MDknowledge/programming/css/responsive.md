# CSS responsive design

- In CSS, `@media (max-width: 700px)` restyles below breakpoints for narrow screens.
- In CSS, mobile-first CSS writes base styles for phones, then `min-width` queries enhance upward.
- In CSS, fluid `clamp(1rem, 2vw, 1.5rem)` type scales between floors and ceilings.
- In CSS, `max-width: 100%` on images and video prevents overflow of containers.
- In CSS, `repeat(auto-fit, minmax(180px, 1fr))` grids adapt column counts with no queries.
- In CSS, the viewport meta tag is required for media queries to match device widths.
- In CSS, `container queries` (`@container`) respond to parent size instead of viewport.
- In CSS, test touch targets of at least 44px for comfortable mobile tapping.
- In CSS, hide decoratively with `display: none` but keep semantic content reachable.
- In CSS, `picture`/`srcset` in HTML pair with CSS for resolution-appropriate assets.
