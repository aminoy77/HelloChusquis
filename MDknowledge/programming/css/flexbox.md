# CSS flexbox

- In CSS, `display: flex` lays children along a main axis defaulting to rows.
- In CSS, `flex-direction: column` stacks vertically; `row-reverse` flips visual order.
- In CSS, `justify-content` aligns on the main axis (center, space-between, flex-end).
- In CSS, `align-items` aligns on the cross axis; `align-self` overrides per child.
- In CSS, `flex-wrap: wrap` flows overflowing items onto new lines instead of shrinking.
- In CSS, `gap: 12px` spaces flex children uniformly without margin hacks.
- In CSS, `flex: 1` grows a child to fill spare space; `flex: 0 0 200px` fixes width.
- In CSS, `order` reorders visually without touching source order (keep DOM logical for a11y).
- In CSS, `align-content` distributes wrapped lines when extra cross-axis space exists.
- In CSS, `margin-left: auto` inside flex pushes one item to the far edge.
