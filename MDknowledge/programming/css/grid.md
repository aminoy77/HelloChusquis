# CSS grid

- In CSS, `display: grid` with `grid-template-columns: repeat(3, 1fr)` builds equal tracks.
- In CSS, `fr` units divide free space proportionally after fixed tracks resolve.
- In CSS, `gap` sets gutters uniformly; `row-gap`/`column-gap` split axes.
- In CSS, `grid-column: 1 / -1` spans an item across the full row width.
- In CSS, named areas via `grid-template-areas` read like ASCII layouts.
- In CSS, `minmax(200px, 1fr)` tracks flex between a floor and available space.
- In CSS, `repeat(auto-fit, minmax(180px, 1fr))` makes responsive grids with zero media queries.
- In CSS, `justify-items`/`align-items` position content inside each cell.
- In CSS, implicit tracks from `grid-auto-rows` size overflow content predictably.
- In CSS, subgrid (`grid-template-columns: subgrid`) aligns nested grids to parent tracks.
