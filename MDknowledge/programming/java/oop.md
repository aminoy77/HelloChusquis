# Java OOP

- In Java, `extends` inherits one superclass while `implements` can adopt many interfaces.
- In Java, `@Override` verifies intended overrides at compile time.
- In Java, `abstract` classes mix implemented and unimplemented methods for frameworks.
- In Java, interfaces with `default` methods evolve APIs without breaking implementors.
- In Java, constructors chain with `this(...)` overloads and `super(...)` parent calls first.
- In Java, `private` fields plus getters/setters encapsulate invariants behind methods.
- In Java, `final` classes and methods close extension points deliberately.
- In Java, `static` factory methods (`of`, `from`) name constructions better than `new`.
- In Java, `equals`/`hashCode` must agree: equal objects share hash codes for collections.
- In Java, `toString` overrides make logs and debugger output readable.
