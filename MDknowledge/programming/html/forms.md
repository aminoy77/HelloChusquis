# HTML forms

- In HTML, `<form action='/s' method='post'>` submits entries to server endpoints.
- In HTML, every input needs an associated `<label for='id'>` for accessibility and click targets.
- In HTML, `name` attributes key submitted values; nameless inputs submit nothing.
- In HTML, `type='email'`, `type='url'`, and `type='number'` validate natively with fitting keyboards.
- In HTML, `required`, `minlength`, `maxlength`, `min`, `max`, and `pattern` constrain input declaratively.
- In HTML, `<select>` with `<option>` offers fixed choices; `multiple` allows several.
- In HTML, `<textarea rows cols>` captures multi-line text that `<input>` cannot.
- In HTML, radio buttons group by shared `name`; checkboxes submit independently.
- In HTML, `<fieldset>` plus `<legend>` groups related controls semantically.
- In HTML, `autocomplete` hints (`email`, `current-password`) help password managers fill correctly.
