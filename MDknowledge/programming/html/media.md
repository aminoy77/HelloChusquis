# HTML media

- In HTML, `<img src alt width height>` embeds images; dimensions prevent layout shift.
- In HTML, `srcset` plus `sizes` serve responsive image resolutions per device.
- In HTML, `<picture>` with `<source media>` art-directs formats like WebP with fallbacks.
- In HTML, `loading='lazy'` defers offscreen images for faster first paint.
- In HTML, `<video controls>` and `<audio controls>` embed players with native UI.
- In HTML, `<source src type>` lists media alternatives; browsers pick the first playable.
- In HTML, `<track kind='captions'>` adds subtitles for accessible video.
- In HTML, `autoplay` is blocked with sound; muted autoplay is the reliable pattern.
- In HTML, `<iframe>` embeds external pages sandboxed via the `sandbox` attribute.
- In HTML, decorative images use empty `alt=''` so screen readers skip them.
