# HTML semantic tags

- In HTML, `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>` outline documents.
- In HTML, exactly one `<main>` per page marks the primary content for assistive tech.
- In HTML, `<article>` wraps self-contained compositions; `<section>` groups thematically.
- In HTML, `<nav>` flags major navigation blocks, not every link list.
- In HTML, `<figure>` plus `<figcaption>` binds images to their captions.
- In HTML, `<time datetime='2024-01-01'>` machine-marks dates inside human text.
- In HTML, `<address>` holds contact info, typically in footers.
- In HTML, `<mark>` highlights relevant passages like search hits.
- In HTML, `<details>`/`<summary>` build native disclosure widgets without JavaScript.
- In HTML, headings must nest in order (`h1` then `h2`) for a coherent outline.
