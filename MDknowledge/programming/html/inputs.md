# HTML inputs

- In HTML, `type='text'` is the default single-line field; `password` masks entry.
- In HTML, `type='email'` validates shape and summons email keyboards on mobile.
- In HTML, `type='number'` with `min`/`max`/`step` constrains numeric entry natively.
- In HTML, `type='date'`, `time`, `month`, and `week` render native pickers per locale.
- In HTML, `type='checkbox'` toggles booleans; `radio` groups exclusives by shared name.
- In HTML, `type='file'` uploads with `accept` filtering MIME types and `multiple` for batches.
- In HTML, `type='range'` sliders pair with live `<output>` displays for feedback.
- In HTML, `type='hidden'` carries state without UI; never trust it for security.
- In HTML, `placeholder` hints format but never replaces visible `<label>` elements.
- In HTML, `disabled` omits values from submission while `readonly` submits uneditable ones.
