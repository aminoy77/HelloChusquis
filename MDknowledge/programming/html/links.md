# HTML links

- In HTML, `<a href='/path'>` links internally; absolute URLs target external sites.
- In HTML, `target='_blank'` opens new tabs; pair with `rel='noopener'` against tabnabbing.
- In HTML, `#fragment` hrefs jump within pages to matching `id` anchors.
- In HTML, `mailto:` and `tel:` hrefs launch email and phone handlers on devices.
- In HTML, `download` attributes suggest filenames for saveable resources.
- In HTML, descriptive link text ('annual report PDF') beats bare 'click here' for everyone.
- In HTML, `rel='nofollow'` marks untrusted links for search engines.
- In HTML, `<link rel='canonical'>` declares the preferred URL among duplicates.
- In HTML, skip links (`<a href='#main'>`) let keyboard users bypass navigation.
- In HTML, visited styling via `:visited` is privacy-limited to color properties only.
