# HTML meta and SEO

- In HTML, `<meta charset='utf-8'>` must appear early to decode the document correctly.
- In HTML, `<title>` sets the tab text and primary search-result headline — keep it unique per page.
- In HTML, `meta name='description'` summarizes pages for search snippets in ~155 characters.
- In HTML, Open Graph tags (`og:title`, `og:image`) control social share cards.
- In HTML, `rel='canonical'` points duplicates at the preferred URL to consolidate ranking.
- In HTML, `robots` meta (`noindex`, `nofollow`) steers crawlers per page.
- In HTML, `lang='en'` on `<html>` aids screen readers, translators, and search.
- In HTML, JSON-LD `<script type='application/ld+json'>` feeds structured data to search engines.
- In HTML, `theme-color` tints mobile browser chrome to match the design.
- In HTML, favicons via `<link rel='icon'>` plus apple-touch-icon cover tabs and home screens.
