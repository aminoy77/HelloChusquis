# HTML tables

- In HTML, `<table>` structures grids with `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`.
- In HTML, `<th scope='col'>` labels columns for screen readers; `scope='row'` labels rows.
- In HTML, `<caption>` titles tables accessibly as the first child element.
- In HTML, `colspan`/`rowspan` merge cells across columns and rows.
- In HTML, tables suit tabular data only; layout belongs to CSS flex and grid.
- In HTML, `<colgroup>`/`<col>` style whole columns without per-cell classes.
- In HTML, keep header cells `<th>` distinct from data cells `<td>` for semantics.
- In HTML, responsive tables wrap in horizontal scroll containers on narrow screens.
- In HTML, `border-collapse: collapse` in CSS merges adjacent cell borders cleanly.
- In HTML, empty data cells should contain `--` or similar, never vanish silently.
