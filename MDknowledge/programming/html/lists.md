# HTML lists

- In HTML, `<ul>` bullets unordered items and `<ol>` numbers ordered steps.
- In HTML, every item needs `<li>`; bare text directly under lists is invalid.
- In HTML, `<ol start='5'>` and `reversed` continue or invert numbering sequences.
- In HTML, `<dl>` with `<dt>` terms and `<dd>` definitions marks glossaries and metadata.
- In HTML, nested lists must sit inside a parent `<li>`, never directly under `<ul>`.
- In HTML, `list-style-type` in CSS switches bullets (disc, square, decimal, roman).
- In HTML, `list-style: none` plus custom markers builds nav menus from lists.
- In HTML, breadcrumbs use ordered lists with aria labels for hierarchy context.
- In HTML, keep list content parallel in phrasing for scannability.
- In HTML, `value` on `<li>` overrides numbering for legal or resume lists.
