# Stored procedures

- In SQL, procedures encapsulate multi-statement logic near the data.
- In SQL, `CREATE PROCEDURE` plus `CALL` separates definition from execution.
- In SQL, `IN/OUT/INOUT` parameters model inputs, results, and both.
- In SQL, error handlers (`DECLARE ... HANDLER`) manage SQLSTATE branches.
- In SQL, functions return values for queries; procedures suit side effects.
- In SQL, version procedures in migration files like application code.
- In SQL, keep business rules in apps; procedures for data-intensive set ops.
- In SQL, `SECURITY DEFINER` runs with owner rights — audit such objects.
