# Greedy algorithms

- Greedy picks local optima hoping for global ones; proof by exchange argument validates.
- Activity selection by earliest finish maximizes non-overlapping bookings.
- Huffman coding assigns short codes to frequent symbols for optimal prefix compression.
- Fractional knapsack sorts by value density; 0/1 knapsack needs DP instead.
- Interval partitioning colors overlapping meetings with minimum rooms greedily.
- Dijkstra is greedy on non-negative edges and provably correct there.
- Coin systems like US denominations work greedily; arbitrary ones need DP.
- Prim/Kruskal grow minimum spanning trees by cheapest safe edges.
- Greedy fails classic counterexamples first — always test the 0/1 knapsack trap.
- Matroid structure characterizes exactly when greedy stays optimal.
