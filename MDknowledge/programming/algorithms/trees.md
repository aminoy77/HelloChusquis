# Trees

- Trees store hierarchies with O(log n) operations when balanced.
- Binary search trees order left < node < right for sorted traversal.
- AVL/red-black trees rebalance on insert, guaranteeing logarithmic height.
- Heaps prioritize extremes: min-heaps pop smallest in O(log n).
- Tries share prefixes for autocomplete and IP routing tables.
- B-trees fan out wide for disk pages backing databases and filesystems.
- Tree traversals: inorder (sorted), preorder (copy), postorder (delete), level-order (BFS).
- Lowest common ancestor queries answer hierarchy questions in O(log n) with binary lifting.
- Segment trees query range aggregates in O(log n) with point updates.
- Unbalanced degenerate trees decay to O(n) linked lists — balance matters.
