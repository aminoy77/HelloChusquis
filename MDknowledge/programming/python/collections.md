# Python collections module

- In Python, `Counter(iterable)` tallies frequencies with `.most_common(n)` rankings.
- In Python, `defaultdict(list)` auto-creates missing values for grouping loops.
- In Python, `deque` appends and pops from both ends in O(1) with optional `maxlen` eviction.
- In Python, `deque(maxlen=n)` builds sliding windows that drop the oldest entries automatically.
- In Python, `namedtuple` creates lightweight immutable records with named field access.
- In Python, `OrderedDict` preserves insertion order explicitly on old interpreters and adds move-to-end helpers.
- In Python, `ChainMap` overlays several mappings so earlier maps shadow later ones.
- In Python, `Counter` arithmetic (`c1 + c2`, `c1 - c2`) merges tallies keeping positive counts.
- In Python, `defaultdict` with `int` counts and with `set` deduplicates groups for free.
- In Python, `namedtuple._asdict()` converts records to dicts for JSON output.
