# Python pprint and textwrap

- In Python, `pprint(data, width=100)` formats nested structures readably.
- In Python, `pprint.saferepr` truncates safely for logging huge objects.
- In Python, `textwrap.dedent` cleans triple-quoted template indentation.
- In Python, `textwrap.fill(text, width=70)` rewraps paragraphs for terminals.
- In Python, `textwrap.shorten` truncates with placeholders for previews.
- In Python, `pprint` sorts dict keys by default for stable snapshots.
- In Python, `textwrap.indent` prefixes every line for code blocks and quotes.
- In Python, `reprlib.repr` caps container reprs preventing log floods.
