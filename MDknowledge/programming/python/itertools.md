# Python itertools module

- In Python, `itertools.chain(a, b)` concatenates iterables lazily without copying.
- In Python, `itertools.islice(it, n)` takes the first n items of any iterator.
- In Python, `itertools.groupby` clusters only consecutive equal keys, so sort first.
- In Python, `itertools.product` builds cartesian products and `permutations`/`combinations` enumerate arrangements.
- In Python, `itertools.cycle` repeats forever and `itertools.repeat(x, n)` emits x exactly n times.
- In Python, `itertools.accumulate` yields running totals, optionally with a custom function.
- In Python, `itertools.zip_longest` pairs uneven iterables with a fill value instead of truncating.
- In Python, `itertools.count(start, step)` generates unbounded arithmetic sequences.
- In Python, `itertools.takewhile`/`dropwhile` split iterators on a predicate boundary.
- In Python, `itertools.pairwise` yields overlapping `(current, next)` tuples for deltas.
