# Python shutil module

- In Python, `shutil.copy(src, dst)` copies file data plus permission bits.
- In Python, `shutil.copytree(src, dst)` clones whole directory trees.
- In Python, `shutil.move(src, dst)` renames or relocates files and directories.
- In Python, `shutil.rmtree(path, ignore_errors=True)` deletes trees robustly in cleanup code.
- In Python, `shutil.disk_usage(path)` reports total, used, and free bytes for capacity guards.
- In Python, `shutil.which('git')` locates executables on PATH before invoking them.
- In Python, `shutil.make_archive` and `shutil.unpack_archive` zip and unzip without extra packages.
- In Python, `shutil.chown` adjusts ownership where the platform permits it.
- In Python, `shutil.copyfileobj(fsrc, fdst)` streams between open file objects efficiently.
- In Python, `shutil.get_terminal_size()` adapts CLI layouts to the actual console width.
