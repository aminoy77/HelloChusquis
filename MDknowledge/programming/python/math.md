# Python math module

- In Python, `math.sqrt`, `math.isclose`, and `math.prod` cover roots, float comparison, and products.
- In Python, `math.floor` rounds down, `math.ceil` rounds up, and `round()` uses banker's rounding on ties.
- In Python, `math.gcd` and `math.lcm` compute greatest divisor and least multiple directly.
- In Python, `math.pi`, `math.e`, `math.tau`, and `math.inf` provide exact constants.
- In Python, `math.comb(n, k)` and `math.perm(n, k)` count combinations and permutations exactly.
- In Python, `math.factorial` handles exact combinatorics that floats would round.
- In Python, `math.log(x, base)` takes an optional base; `math.log2` and `math.log10` are exact shortcuts.
- In Python, `math.hypot(x, y)` computes Euclidean distance without overflow risk.
- In Python, `math.fsum` sums floats more accurately than the builtin `sum`.
- In Python, `math.isnan` and `math.isinf` detect special float values safely.
