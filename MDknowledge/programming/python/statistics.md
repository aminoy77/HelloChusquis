# Python statistics module

- In Python, `statistics.mean`, `median`, and `mode` summarize centers of numeric data.
- In Python, `statistics.stdev` needs at least two points; `pstdev` treats data as the whole population.
- In Python, `statistics.median` resists outliers better than `mean` on skewed samples.
- In Python, `statistics.quantiles(data, n=4)` cuts distributions into quartiles.
- In Python, `statistics.correlation(x, y)` measures linear association between paired series.
- In Python, `statistics.linear_regression(x, y)` returns slope and intercept of the best-fit line.
- In Python, `statistics.NormalDist(mu, sigma)` models gaussians with cdf, pdf, and overlap methods.
- In Python, `statistics.fmean` computes faster float means for large iterables.
- In Python, `statistics.multimode` lists all most-common values instead of picking one.
- In Python, `statistics.variance` uses sample (n-1) normalization by default.
