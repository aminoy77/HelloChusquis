# Python bisect and heapq

- In Python, `bisect_left(a, x)` finds insertion points keeping lists sorted.
- In Python, `heapq` implements min-heaps with `heappush` and `heappop`.
- In Python, `heapq.nlargest/nsmallest` beat full sorts for top-k queries.
- In Python, `bisect` requires pre-sorted input or results silently mislead.
- In Python, `heapq.merge` lazily merges sorted iterables without copying.
- In Python, `insort` inserts maintaining order in O(n) shifting time.
- In Python, max-heaps negate values (`-x`) since only min-heaps exist.
- In Python, `bisect` plus `pop` implements simple priority queues on lists.
