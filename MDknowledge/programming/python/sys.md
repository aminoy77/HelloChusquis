# Python sys module

- In Python, `sys.argv` holds command-line arguments with the script name at index 0.
- In Python, `sys.exit(code)` raises SystemExit; nonzero codes signal failure to callers.
- In Python, `sys.path` lists module search directories; `.pth` files and PYTHONPATH extend it.
- In Python, `sys.version_info` exposes the running interpreter version for feature gates.
- In Python, `sys.stdin`, `sys.stdout`, and `sys.stderr` are the standard text streams.
- In Python, `sys.getsizeof(obj)` reports shallow memory use, excluding referenced objects.
- In Python, `sys.setrecursionlimit(n)` raises the recursion ceiling at stack-overflow risk.
- In Python, `sys.excepthook` customizes uncaught-exception reporting for CLI polish.
- In Python, `sys.platform` starts with 'linux', 'darwin', or 'win32' for OS branching.
- In Python, `sys.intern` deduplicates strings to speed repeated equality checks.
