# Git remotes

- In Git, `git remote -v` lists fetch/push URLs to audit where code flows.
- In Git, `git remote add origin <url>` links local work to hosted repositories.
- In Git, `git remote set-url` rotates URLs after host migrations or credential changes.
- In Git, `git fetch --prune` drops deleted remote branches from local tracking.
- In Git, `git push -u origin HEAD` publishes and tracks the current branch once.
- In Git, `git pull --rebase` replays local commits onto fetched work for linear history.
- In Git, `git ls-remote` inspects remote refs without downloading anything.
- In Git, `git remote show origin` reports tracking and push/fetch mappings.
- In Git, multiple push URLs on one remote mirror releases to several hosts.
- In Git, SSH remotes (`git@host:...`) use keys; HTTPS remotes use tokens or helpers.
