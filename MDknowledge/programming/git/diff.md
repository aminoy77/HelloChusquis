# Git diff

- In Git, `git diff` shows unstaged work and `git diff --staged` shows the next commit.
- In Git, `git diff main...feature` compares a branch against its merge base.
- In Git, `git diff --stat` summarizes files changed before reading full patches.
- In Git, `git diff --word-diff` highlights intra-line edits in prose and configs.
- In Git, `git diff <sha1> <sha2> -- path/` scopes comparisons to one directory.
- In Git, `--color-words` and `--check` catch whitespace errors while reviewing.
- In Git, `git difftool` opens visual diffs configured via `diff.tool`.
- In Git, external diffs (`diff.external`) route patches to custom reviewers.
- In Git, `git range-diff` compares two versions of a patch series during rebases.
- In Git, `git apply --check` dry-runs patches before touching the tree.
