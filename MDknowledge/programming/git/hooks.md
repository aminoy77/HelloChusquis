# Git hooks

- In Git, hooks in `.git/hooks/` fire on commits, pushes, and checkouts.
- In Git, `pre-commit` lints/tests before commits land locally.
- In Git, `commit-msg` validates message conventions automatically.
- In Git, `pre-push` runs suites before network transfers waste CI.
- In Git, hooks don't clone by default; share via committed scripts plus docs.
- In Git, frameworks (husky, pre-commit) manage hooks cross-platform.
- In Git, server-side `update` hooks enforce branch policies centrally.
- In Git, keep hooks fast (seconds) or developers bypass them with --no-verify.
