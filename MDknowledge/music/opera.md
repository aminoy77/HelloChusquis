# Opera essentials (example)

- Opera fuses singing, orchestra, drama, and staging into total theater.
- Voice types rank soprano, mezzo, tenor, baritone, bass by range.
- Arias freeze action for emotional display; recitatives advance plot rapidly.
- Monteverdi's Orfeo (1607) counts among the first great operas.
- Mozart comedies plus Verdi tragedies anchor standard repertoire.
- Wagner's Ring spans four evenings with leitmotif architecture.
- Supertitles (1980s innovation) finally made plots followable live.
- Castrati roles now go to countertenors or mezzo-sopranos.
- Opera houses (La Scala, Met) commission new works alongside classics.
- Rehearsal pianists (répétiteurs) drill singers before orchestras arrive.
