**Files:**

**Interfaces:**

- Produces: `test_pyproject_matches_changelog` — fails if they drift again

- [ ] **Step 1: Write the failing test**

```python
"""Phase 0: pyproject version == latest ## X.Y in CHANGELOG.md."""
import re
from pathlib import Path


def _root():
    return Path(__file__).resolve().parent.parent


def test_pyproject_matches_changelog():
    root = _root()
    m = re.search(r'^version\s*=\s*"([^"]+)"', (root / "pyproject.toml").read_text(), re.M)
    assert m, "version not found in pyproject.toml"
    versions = re.findall(r"^## (\d+\.\d+)", (root / "CHANGELOG.md").read_text(), re.M)
    assert versions, "no ## X.Y versions in CHANGELOG.md"
    assert m.group(1) == versions[0], f"pyproject={m.group(1)} vs changelog={versions[0]}"
```

- [ ] **Step 2: Run test to verify it fails**
