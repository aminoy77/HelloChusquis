How It Works

Three steps. No setup wizard needed.

Install it, configure one API key, and start asking questions. The agent handles the rest.

Step 1
Install
One pip command. Works on macOS, Linux, and Windows. Python 3.10+ required.
Step 2
Add an API key
Paste a free OpenRouter or Groq key. The agent auto-falls back if one provider goes down.
Step 3
Ask anything
Search the web, run code, manage files, automate browsers. The agent picks the right tools.

Features

What it actually does.

No vaporware. Every feature ships working.

🔄
Multi-provider fallback
Configure Groq, OpenRouter, Ollama, OpenAI, and more. If one fails, the next one picks up automatically.
🧠
Persistent memory
Remembers past sessions. Learns from mistakes. Gets better every time you use it.
📋
Task planner
Complex tasks get broken into steps. You review the plan, then the agent executes each step.
🌐
Web interface
Chat from your browser at localhost:8000. Provider status, plugins, and memory stats in the sidebar.
🔍
Browser automation
Open URLs, click buttons, fill forms, take screenshots. Real Playwright automation, not a toy wrapper.
🔒
Workspace permissions
Only accesses directories you explicitly allow. Runtime prompts for new paths. Your files stay yours.
📡
REST API with streaming
Expose your agent over HTTP. SSE streaming for real-time responses. Rate limiting included.
🧩
Plugin system
Install community plugins or build your own. The agent can build integrations for you on demand.
🛡️
Security checks
AI-powered safety evaluator blocks dangerous commands before they run. Configurable strictness.

Get Started

Install in one command.

Pick the method that works for you.

Option 1
pip (recommended)
pip install hellochusquis

Requires Python 3.10+. Adds the hellochusquis command to your PATH.

Option 2
curl installer
curl -sSL https://raw.githubusercontent.com/aminoy77/HelloChusquis/main/install.sh | bash

Downloads and installs everything. macOS and Linux only.

Option 3
From source
git clone https://github.com/aminoy77/HelloChusquis.git && cd HelloChusquis && pip install -e .

For contributors. Editable install — changes take effect immediately.
