Built-in Tools

Everything you need, nothing you don't.

Four core tools that cover 90% of developer workflows. No bloated plugin system required.

🖥️

Shell Execution

Run any terminal command directly from chat. Build, test, deploy — without leaving the conversation.

$ hellochusquis → shell("docker build -t app .")
🐍

Code Interpreter

Execute Python code in real-time. Data analysis, scripting, prototyping — all sandboxed and safe.

$ hellochusquis → code("print(sum(range(100)))")
📁

File Management

Read, write, delete, and list files. Build entire projects without touching your editor.

$ hellochusquis → files(write, "app.py", content)
🌐

Web Search

Search the web via DuckDuckGo. Get current information without leaving the terminal.

$ hellochusquis → web_search("Python 3.13 features")
