CLI Commands

Terminal Commands

  • hellochusquis Start interactive chat
  • hellochusquis web Open web interface (localhost:8000)
  • hellochusquis api Start REST API server (port 8080)
  • hellochusquis config Open setup wizard
  • hellochusquis config --show Display current configuration
  • hellochusquis config --api-keys Edit API keys only
  • hellochusquis config --providers Edit providers only

In-Chat Slash Commands

  • /help Show all available commands
  • /status Provider status and response times
  • /clear Clear conversation history
  • /plan <task> Force multi-step plan for complex tasks
  • exit Quit the session

Plugin Management

  • hellochusquis install <plugin> Install a community plugin
  • hellochusquis uninstall <plugin> Remove a plugin
  • hellochusquis plugins List installed plugins
  • hellochusquis build Build the project
  • hellochusquis learn Run learning pipeline

Environment Variables

  • HELLOCHUSQUIS_API_KEY Sets the web UI auth key
  • HELLOCHUSQUIS_AUTH=1 Enable web UI auth
  • DEBUG=1 Verbose logs
  • HELLOCHUSQUIS_UNSAFE_MODE=1 Skip security checks

Productivity Tips

Multi-step tasks with /plan

Complex tasks get auto-detected, but you can force a plan: /plan deploy my app to AWS with monitoring. Review steps before execution.

Web interface

Run hellochusquis web to chat from your browser at localhost:8000. Supports voice input/output, themes, streaming, and chat export.

REST API with streaming

Expose your agent over HTTP: hellochusquis api --port 8080. Supports SSE streaming, rate limiting, and health checks at /health.

Provider failover

Add multiple providers. If one hits rate limits or goes down, the agent automatically switches to the next one. Zero downtime.

Persistent memory

The agent remembers past sessions. Feedback helps it learn your preferences. Memory persists across sessions in ~/.hellochusquis/.

Pick your model

In the web UI, choose any provider and model from the input bar — right next to the composer. Your selection is remembered.

Built-in Tools

Everything you need. Nothing you don't.

Four core tools that cover 90% of developer workflows. Stop installing plugins for basic tasks.

Shell Execution

Stop switching between terminal and chat. Run builds, tests, and deployments directly from your conversation.

$ hellochusquis → shell("docker build -t app .")

Code Interpreter

Prototype and debug without context switching. Run Python code instantly, analyze data, and test ideas live.

$ hellochusquis → code("print(sum(range(100)))")

File Management

Build entire projects without leaving the conversation. Read, write, and organize files on the fly.

$ hellochusquis → files(write, "app.py", content)

Web Search

Get current information without tab-switching. Search docs, find solutions, and pull live data into your workflow.

$ hellochusquis → web_search("Python 3.13 features")
