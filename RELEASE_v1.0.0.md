## HelloChusquis v1.0.0 — First stable release

After months of development, HelloChusquis is ready.

### What's inside

**Multi-provider fallback**
Automatically switches between OpenRouter, Ollama, OpenAI, Anthropic, Gemini, Groq and 15+ more when one fails or hits rate limits. Zero config required.

**128 integrations**
Stripe, Twilio, HubSpot, Supabase, AWS, Discord, Notion, Linear, and 120+ more. Each one callable directly from your terminal.

**Browser automation**
Controls a real browser with human-like mouse movement — non-linear paths, variable speed, natural click timing.

**Auto-Tool Builder**
Describe an integration you need. It researches the API, generates the code, and saves it as a plugin.

**Voice I/O**
Speak and listen in the web interface. 12+ languages.

**Persistent memory**
SQLite-backed conversation memory across sessions.

**REST API mode**
`hellochusquis api --port 8080` — exposes a /chat endpoint.

### Install

pip install hellochusquis

This is v1.0.0. Things will break. Open an issue when they do — that's how this gets better.
